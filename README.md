# Praca_dyplomowa
Repozytorium zawierające kod, skrypty oraz inne elementy wykrozystane w trakcie realizacji pracy dyplomowej. Tytuł pracy: Platforma testowa dla celów uruchomienia wielowirnikowych modeli latających.

Folder Matlab zaweira część z wykorzystanych skryptów.

Folder Pomiary zawiera część danych zebranych w ramach badań.

Folder SImulink zaweira model simulinka używany do zpaisu danych z platformy.

Folder System pomiarowy zawiera kod sterujący systemem pomiarowym.
